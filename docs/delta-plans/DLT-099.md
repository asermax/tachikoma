### Steps

#### Step 3: Create `TranscriptArchiveProcessor`

- Create: `src/tachikoma/memory/transcripts.py`
- What to do:
  - Module-level `_log = logger.bind(component="transcript_archive")`.
  - Class `TranscriptArchiveProcessor(PostProcessor)` with `__init__(self, agent_defaults: AgentDefaults)` storing `self._cwd = agent_defaults.cwd`.
  - `async def process(self, session: Session) -> None`:
    - Return early with a `debug` log when `session.transcript_path is None` or `session.sdk_session_id is None`.
    - Compute `dest_dir = self._cwd / "memories" / "transcripts"` and `dest = dest_dir / f"{session.sdk_session_id}.jsonl"`.
    - Defensively call `dest_dir.mkdir(parents=True, exist_ok=True)` (per D6/S4).
    - Invoke `shutil.copy2(Path(session.transcript_path), dest)`.
    - Catch `FileNotFoundError` → `_log.warning(...)` with source + destination paths; return.
    - Catch `OSError` (covers `PermissionError`, disk-full, and other I/O failures without masking unrelated programmer errors) → `_log.error(...)` with session id + paths; return (matches `StaleWorkflowCleanupProcessor`'s swallow-and-log policy).
    - On success, `_log.info("Archived transcript: session=..., dest=...")`.
- Verify: `uv run ty check` passes; import works from `tachikoma.memory.transcripts`.

#### Step 4: Unit tests for `TranscriptArchiveProcessor`

- Create: `tests/memory/test_transcripts.py`
- What to do:
  - Add a `_make_session(transcript_path=None, sdk_session_id="sdk-123")` helper mirroring `tests/git/test_processor.py`.
  - Use `tmp_path` for both a fake SDK transcript file and the workspace cwd.
  - Construct processor via `TranscriptArchiveProcessor(AgentDefaults(cwd=tmp_path / "workspace"))`.
  - Tests to write (one per spec AC):
    - **Happy path (R0, R1, R6, R8)**: source file exists with known bytes; after `process`, `<cwd>/memories/transcripts/<sdk-session-id>.jsonl` exists and is byte-identical.
    - **Null `transcript_path`**: `process` returns normally; destination file is not created.
    - **Null `sdk_session_id`**: `process` returns normally; destination file is not created.
    - **Source file missing** (`transcript_path` points to a non-existent path): `process` returns normally, no file created. Prefer asserting the warning log via a `loguru` sink (e.g., `caplog`-style fixture) to strengthen the R3 guarantee; fall back to no-raise/no-file assertions if log capture is impractical.
    - **Filesystem error on copy**: mock `shutil.copy2` with `mocker.patch` to raise `PermissionError`; assert `process` returns without raising and (preferably) that an error log is emitted.
    - **Idempotency (R4)**: call `process` twice with the same session against the same workspace, then modify the source, call again, and assert the destination contents equal the latest source bytes.
    - **Self-healing mkdir (D6)**: pre-delete `memories/transcripts/` between constructing the processor and invoking `process`; assert copy still succeeds.
  - Each test is `async def` and uses `await processor.process(session)`.
