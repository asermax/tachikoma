### Steps

#### Step 1: Create StderrAccumulator class

- Create: `src/tachikoma/sdk_query.py`
- What to do: Define `StderrAccumulator` class with:
  - `__init__`: Initialize empty `list[str]` buffer
  - `__call__(self, line: str) -> None`: Append line to buffer, wrapped in try/except that silently swallows all exceptions (R3)
  - `get(self, max_chars: int = 10_000) -> str | None`: Join buffer lines with `"\n"`. Return `None` if empty (no noise). If total length exceeds `max_chars`, return `"[stderr truncated]\n"` + tail slice (R4)
- Test: Unit tests in `tests/test_sdk_query.py`, class `TestStderrAccumulator`:
  - `test_accumulates_lines` — multiple `__call__` invocations, `get()` returns newline-joined
  - `test_returns_none_when_empty` — fresh instance, `get()` returns `None`
  - `test_truncates_with_marker` — exceed `max_chars`, verify `[stderr truncated]` prefix and tail content
  - `test_swallows_callback_errors` — mock list.append to raise, verify no exception propagates
  - `test_custom_max_chars` — pass custom threshold to `get()`

# - __call__ appends to buffer with silent error swallowing (R3)

#### Step 2: Create stderr_aware_query() wrapper

- Modify: `src/tachikoma/sdk_query.py`
- What to do: Define `stderr_aware_query()` async generator:
  - Signature mirrors SDK `query()`: `prompt: str | AsyncIterable[dict[str, Any]]`, `options: ClaudeAgentOptions | None = None`, `transport: Transport | None = None` — all keyword-only. `transport` defaults to `None` and is passed through to SDK.
  - If `options is None`, create a fresh `ClaudeAgentOptions()` so the accumulator can be installed
  - Create fresh `StderrAccumulator`, install via `options.stderr = accumulator`
  - Delegate to SDK `query(prompt=prompt, options=options, transport=transport)` in a try block
  - Re-yield each message from the inner generator (preserving DES-005 full consumption)
  - On `ProcessError`: read `accumulator.get()`, if not None log with `_log.error("SDK query failed: err={err}, stderr={stderr}", err=str(exc), stderr=stderr)`, else log without stderr field. Re-raise unchanged.
  - On success: accumulator discarded naturally (garbage collected)
- Test: Additional tests in `tests/test_sdk_query.py`, class `TestStderrAwareQuery`:
  - `test_yields_all_messages_on_success` — mock SDK query to yield messages, verify all re-yielded, no log call
  - `test_logs_stderr_on_process_error` — mock SDK query to raise ProcessError after stderr lines, verify log includes `stderr=` field
  - `test_reraises_process_error_unchanged` — verify exact same exception object re-raised
  - `test_no_stderr_field_when_buffer_empty` — ProcessError with no stderr lines, verify log call omits stderr
  - `test_installs_accumulator_on_options` — verify `options.stderr` is set before SDK delegation
  - `test_creates_options_when_none` — call with `options=None`, verify a fresh `ClaudeAgentOptions` is created with accumulator installed

```python
# In src/tachikoma/sdk_query.py, after StderrAccumulator:

# stderr_aware_query() async generator
# - Creates StderrAccumulator, installs on options.stderr
# - Handles options=None by creating fresh ClaudeAgentOptions
# - Delegates to SDK query(), re-yields all messages
# - On ProcessError: log stderr if present, re-raise unchanged
```
