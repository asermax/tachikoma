### Steps

#### Step 9: Add _validate_post_processors() to loader.py

- Modify: `src/tachikoma/plugins/loader.py`
- What to do: Add `_validate_post_processors(manifest, plugin_dir, alias, validated_config, agent_defaults) -> list[PostProcessor]` after `_validate_providers()`. Import phase constants (`MAIN_PHASE`, `_VALID_PHASES`) from `tachikoma.post_processing`. Mirror the pattern: iterate `manifest.post_processors.values()`, build path as `plugin_dir / "post_processors" / f"{module_name}.py"`, check file exists, import via `_import_handler_module()`, find concrete `PostProcessor` subclasses (skip abstract). For each class: validate `__init__` accepts `config` using `inspect.signature(cls.__init__)` and checking `"config" in sig.parameters`; validate `phase` attribute value is in `_VALID_PHASES` (fail with diagnostic listing valid values); build kwargs dict with `config=validated_config`; conditionally add `agent_defaults=` if `"agent_defaults" in sig.parameters` (signature inspection — avoids requiring every processor to accept it); instantiate with `cls(**kwargs)`. Return the list.
- Note: Plugin processors extending `PromptDrivenProcessor` that don't override `process()` automatically inherit DES-004 behavior (resumption augmentation, context summary injection). Processors that override `process()` must follow those conventions manually — this is a documented convention, not enforced by validation.
- Test: Will be verified in Step 12.

- Test: Will be verified in Step 12.

#### Step 11: Thread AgentDefaults through plugins_hook and PluginManager

Pass `agent_defaults=agent_defaults` to `PluginManager()` constructor.

- What to do: Add `agent_defaults: AgentDefaults` keyword parameter to `PluginManager.__init__()`. Store as `self._agent_defaults`. Import `AgentDefaults` from `tachikoma.agent_defaults`.
