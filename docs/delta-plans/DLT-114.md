- `src/tachikoma/agent_defaults.py` — current `merge_env()` to modify (lines 31-49)
- `tests/test_agent_defaults.py` — existing `TestMergeEnv` class to extend

### Steps

#### Step 1: Extend merge_env() with auto_injected parameter

- Modify: `src/tachikoma/agent_defaults.py`
- What to do:
  - Add `auto_injected: dict[str, str] | None = None` parameter to `merge_env()`
  - Change merge expression from `{**HARDCODED_ENV, **config_env}` to `{**(auto_injected or {}), **config_env, **HARDCODED_ENV}`
  - Collision check remains unchanged: `set(HARDCODED_ENV) & set(config_env)`
  - Update docstring to document the new parameter and layering order
- Test: Existing tests still pass (backward compatible — default `None` produces same behavior)
- Note: Timezone validation is a pre-existing invariant at the config layer (`TaskSettings` validators). `merge_env()` receives a pre-validated string — no new validation needed here.

#### Step 2: Add tests for auto-injected layering

- Modify: `tests/test_agent_defaults.py`
- What to do: Add new test methods to `TestMergeEnv`:
  - `test_auto_injected_included_in_result` — `auto_injected={"TZ": "America/Buenos_Aires"}` with empty config_env → result contains TZ
  - `test_user_override_wins_over_auto_injected` — `auto_injected={"TZ": "America/Buenos_Aires"}`, `config_env={"TZ": "UTC"}` → result has `TZ=UTC` (user wins)
  - `test_auto_injected_no_collision_error` — `auto_injected={"TZ": "..."}`, `config_env={"TZ": "UTC"}` → no ValueError raised
  - `test_auto_injected_with_hardcoded_key_no_error` — `auto_injected={"CLAUDE_CODE_DISABLE_AUTO_MEMORY": "0"}` → no ValueError raised, proving auto_injected bypasses collision check
  - `test_auto_injected_shadowed_by_hardcoded` — `auto_injected={"CLAUDE_CODE_DISABLE_AUTO_MEMORY": "0"}` → result has `CLAUDE_CODE_DISABLE_AUTO_MEMORY=1` (hardcoded wins silently; defense in depth per design)
  - `test_auto_injected_none_backward_compatible` — `auto_injected=None` → same result as current behavior
- Test: `just test tests/test_agent_defaults.py`
