#### Step 9: Create send_file tool server factory

- Modify: `src/tachikoma/telegram/tools.py`
- What to do: Add the Pydantic args model, extracted handler, and factory function following DES-006:
  - `SendFileArgs` Pydantic model: `file_path: str` (required), `caption: str | None = None` with `Field(max_length=1024)`
  - `handle_send_file(file_path: str, caption: str | None, bot: Bot, chat_id: int, workspace_path: Path) -> dict` — extracted async handler:
    1. Call `validate_file_path()` → catch ValueError → return `is_error` response
    2. Call `detect_media_type()` on resolved path
    3. Create `FSInputFile(resolved_path)`
    4. Dispatch to `bot.send_photo/send_audio/send_video/send_document` based on category, passing `caption=caption`
    5. On success → return `{"content": [{"type": "text", "text": "File sent: {filename}"}]}`
    6. On `TelegramAPIError` → return `{"is_error": True, "content": [{"type": "text", "text": str(error)}]}`
  - `create_send_file_server(bot: Bot, chat_id: int, workspace_path: Path) -> McpSdkServerConfig` — factory:
    1. Define `@tool("send_file", description, SendFileArgs.model_json_schema())` closure
    2. Parse args via `SendFileArgs.model_validate(args)`
    3. Call `handle_send_file()` with closure-captured bot/chat_id/workspace_path
    4. Return `create_sdk_mcp_server(name="send-file", tools=[send_file])`

```python

# def create_send_file_server(bot, chat_id, workspace_path) -> McpSdkServerConfig:
```
