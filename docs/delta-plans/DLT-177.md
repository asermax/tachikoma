#### Step 1: Add `format_memory_index()` helper to `memory/index.py`

- Create/modify: `src/tachikoma/memory/index.py`
- What to do: Add a new function `format_memory_index(memory_type: str, raw_content: str) -> str | None` that:
  - Accepts the memory type label (`"facts"` or `"preferences"`) and the raw MEMORY.md file content
  - Parses entries matching the `[Name](./path.md): description` format using a regex
  - Skips malformed entries with a debug-level log warning
  - Skips the entire file if no well-formed entries are found (returns `None`)
  - Returns a formatted section string with:
    - A header line (e.g., `## Facts Index` or `## Preferences Index`)
    - A one-paragraph description of the memory type and usage instructions
    - The well-formed MEMORY.md entries preserved as-is

  ```python
  # In src/tachikoma/memory/index.py, after the existing imports and before
  # DESCRIPTION_WORKER_PROMPT:

  # Regex for MEMORY.md entries: [Human-readable Name](./path.md): One-line description
  _INDEX_ENTRY_RE = re.compile(
      r"^\[([^\]]+)\]\(\./([^)]+\.md)\):\s*(.+)$", re.MULTILINE
  )

  # Type descriptions for injected sections
  _TYPE_DESCRIPTIONS = {
      "facts": (
          "Stable reference information: personal details, key people, "
          "technical decisions.\nBrowse the entries below. When a file seems "
          "relevant to the current conversation,\nread it with the Read tool "
          "to get the full content."
      ),
      "preferences": (
          "Subjective choices about how things should be done.\nBrowse the "
          "entries below. When a file seems relevant to the current "
          "conversation,\nread it with the Read tool to get the full content."
      ),
  }

  def format_memory_index(memory_type: str, raw_content: str) -> str | None:
      """Format a MEMORY.md file's raw content into an injectable section.

      Parses entries matching [Name](./path.md): description. Malformed
      entries are skipped with a debug log. Returns None if no well-formed
      entries are found.
      """
      # Find all well-formed entries
      entries = _INDEX_ENTRY_RE.findall(raw_content)
      if not entries:
          return None

      # Reconstruct well-formed entry lines from parsed groups
      lines = [f"[{name}](./{path}): {desc}" for name, path, desc in entries]

      # Check for malformed lines (lines that look like entries but don't parse)
      # ... log debug warnings for any that don't match

      description = _TYPE_DESCRIPTIONS.get(
          memory_type,
          "Browse the entries below. When a file seems relevant, read it "
          "with the Read tool.",
      )

      return (
          f"## {memory_type.title()} Index\n\n"
          f"{description}\n\n"
          + "\n".join(f"- {line}" for line in lines)
      )
  ```

#### Step 2: Add `load_memory_indexes()` helper to `memory/index.py`

- Create/modify: `src/tachikoma/memory/index.py`
- What to do: Add `load_memory_indexes(workspace_path: Path) -> list[tuple[str, str]]` that:
  - Iterates over `("facts", "preferences")` memory types
  - For each, reads `memories/<type>/MEMORY.md`
  - Calls `format_memory_index()` on the content
  - Collects `(owner_tag, formatted_content)` tuples where owner_tag is `"memory_index"`
  - Skips missing/empty/malformed files silently (no error, no warning for missing; debug log for malformed entries)

  ```python
  # In src/tachikoma/memory/index.py, after format_memory_index:

  _INDEXABLE_TYPES = ("facts", "preferences")

  def load_memory_indexes(workspace_path: Path) -> list[tuple[str, str]]:
      """Read and format both facts and preferences MEMORY.md files.

      Returns list of (owner_tag, formatted_content) tuples. Skips
      missing/empty files silently.
      """
      results: list[tuple[str, str]] = []
      memories_root = workspace_path / "memories"

      for memory_type in _INDEXABLE_TYPES:
          index_path = memories_root / memory_type / "MEMORY.md"

          try:
              raw_content = index_path.read_text()
          except FileNotFoundError:
              continue
          except OSError as err:
              _log.debug(
                  "Memory index unreadable: type={type} err={err}",
                  type=memory_type,
                  err=str(err),
              )
              continue

          formatted = format_memory_index(memory_type, raw_content)
          if formatted is not None:
              results.append(("memory_index", formatted))

      return results
  ```
