#### Step 8: Implement provide() body — fork logic, path parsing, dedup, file reads

- Modify: `src/tachikoma/memory/context_provider.py`
- What to do: Implement the full `provide()` method following the design's data flow (11 steps):
  1. Extract loaded memory paths from `existing_entries` via `extract_memory_paths()`
  2. Build search prompt (embed user message)
  3. Branch on `sdk_session_id`: if available → `ClaudeAgentOptions(resume=sdk_session_id, fork_session=True, ...)`, else → standalone `ClaudeAgentOptions(...)` (same as current but without fork/resume). Both use: model from agent_defaults, effort="low", max_turns=8, allowed_tools=["Read", "Glob", "Grep"], permission_mode="bypassPermissions", cwd, cli_path, env from agent_defaults.
  4. Call `query(prompt, options=options)`, fully consume generator per DES-005
  5. On `ResultMessage`: if error → log warning; if `NO_RELEVANT_MEMORIES` → no paths; if content → parse file paths (one per line, strip whitespace)
  6. **Path validation**: resolve each returned path against `self._agent_defaults.cwd` using `Path.resolve()`. Check that the resolved path starts with `(self._agent_defaults.cwd / "memories").resolve()`. Reject any path not within `memories/` (including `../` traversal or paths in other directories). Log warning for rejected paths per DES-002.
  7. Filter out paths already in loaded set (dedup)
  8. For each new path: `Path.read_text()`, create `ContextResult(tag="memories", content=file_content, metadata={"memory_path": path})`
  9. If file read fails (FileNotFoundError) → skip that file, log warning, continue with remaining
  10. Return list of ContextResults, or None if empty
  11. Outer try/except catches all exceptions → log per DES-002 → return None
- Test: `just typecheck` and `just test tests/memory/test_context_provider.py`
