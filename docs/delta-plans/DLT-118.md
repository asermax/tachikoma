#### Step 4: Implement `resolve_chain` via post-order DFS with visited-set

- Modify: `src/tachikoma/skills/registry.py` (public methods section, near `get_workflow`)
- What to do: Add a new public method. DFS enters the anchor, recurses into each declared dep in declared order, skips visited (cycle/dedup) and unknown (missing-skill) names, appends on return (post-order → deps-first, anchor last). Memoize result under `skill_name` key. Raise `KeyError` if `skill_name` is not in `_skills` (contract per design).

```python
def resolve_chain(self, skill_name: str) -> list[Skill]:
    """Return the transitive dependency chain for a skill, deps-first with anchor last.

    Cycles (including self-reference) are broken via a visited-set; unknown dep
    names are silently skipped. Results are memoized until the next refresh() or
    add_source() call.

    Raises KeyError if skill_name is not in self._skills.
    """
    # Cache check before the anchor lookup: cache hit returns the previously
    # computed chain without re-validating skill presence (cache entries are
    # invalidated on every mutation path).
    if skill_name in self._chain_cache:
        return self._chain_cache[skill_name]

    if skill_name not in self._skills:
        raise KeyError(skill_name)

    visited: set[str] = set()
    chain: list[Skill] = []

    def dfs(name: str) -> None:
        # Cycle / diamond / self-reference: break back-edges before descending.
        if name in visited:
            return
        # Unknown dep (typo, deleted skill): silent skip during traversal —
        # the load-time _validate_deps pass is the authoritative warning point.
        if name not in self._skills:
            return
        visited.add(name)
        current = self._skills[name]
        for dep in current.depends_on:
            dfs(dep)
        # Post-order append → deps-first, anchor last.
        chain.append(current)

    dfs(skill_name)
    self._chain_cache[skill_name] = chain
    return chain
```

#### Step 5: Add `_validate_deps` post-discovery validation pass

- Modify: `src/tachikoma/skills/registry.py` (private methods section)
- What to do: One-pass walk of `_skills` emitting at most one warning per dependent skill, enumerating all missing dep names for that skill.

```python
def _validate_deps(self) -> None:
    """Log one warning per dependent skill whose depends_on contains unknown names.

    Walks self._skills once after a load path populates it. Emits at most one
    warning per dependent skill; the warning enumerates all missing dep names
    for that skill.
    """
    for name, skill in self._skills.items():
        if not skill.depends_on:
            continue
        # Build the missing list in declared order so the warning is stable.
        missing = [d for d in skill.depends_on if d not in self._skills]
        if missing:
            _log.warning(
                "Skill declares unknown dependencies: skill={skill}, missing={missing}",
                skill=name,
                missing=missing,
            )
```

#### Step 6: Wire `_validate_deps` + cache management into `__init__`, `refresh`, `add_source`

- Modify: `src/tachikoma/skills/registry.py`
- What to do:

```python
# In __init__, after the for-loop that calls _discover for each source:
self._validate_deps()

# In add_source, BEFORE the _discover call:
# Clear cache at the start so newly-added skills can't be masked by stale
# chain results that were computed against the older _skills state.
self._chain_cache.clear()
# Then: self._skill_sources.append(path); self._discover(path)
# After _discover:
self._validate_deps()

# In refresh(), clear the cache at the SAME moment the three existing
# fresh-dict swaps happen (i.e., alongside self._agents/_skills/_workflows = {}
# BEFORE the try block). Design wording: "cleared alongside the fresh-dict swap."
# Correctness is identical whether placed inside or outside the try block —
# no cache save/restore on failure (empty cache is consistent with any _skills
# state; next resolve_chain call pays cold-recompute). We align with the
# design's wording by placing it outside the try block alongside the other swaps.
self._chain_cache = {}
# ... existing for source in self._skill_sources: _discover(source) ...
# Inside the try block, after the for-loop and BEFORE `self._dirty = False`:
self._validate_deps()
# Rationale: _validate_deps inside the try ensures any unexpected exception
# there is caught by the existing swap-on-failure path (old dicts restored,
# _dirty remains True for retry).
```

- Explicit note to implementation agent: on `refresh()` failure the `except` branch restores `_agents` / `_skills` / `_workflows` — do **not** add `_chain_cache` to that restore. Per design "Cache-consistency under refresh" invariant, an empty cache is always consistent with any `_skills` state; cold-recompute is the only cost.

  - `test_add_source_clears_chain_cache`: populate cache, `add_source` with a new directory that satisfies a previously-unknown dep, assert the new chain reflects the added source.

#### Step 7: Expand classification results through `resolve_chain` with first-seen dedup

- Modify: `src/tachikoma/skills/context_provider.py` (`SkillsContextProvider.provide`)
- What to do: Between the block that populates `detected_names` and the block that builds `results`, insert a chain-expansion pass. Keep the existing `extract_skill_names(existing_entries)` dedup path; just apply it to the expanded ordered chain instead of directly to `detected_names`.

```python
# In provide(), after `if not detected_names: return None`:

# Expand each detected skill into its transitive dependency chain. First-seen
# wins on overlap across sibling chains — preserves deps-first ordering within
# each chain and classification order across chains (design §Provider pipeline).
ordered_skills: list[Skill] = []
seen: set[str] = set()

for name in detected_names:
    # Per-skill try/except: one failing chain (e.g., hypothetical recursion
    # overflow) must not block the message (parent feature R14 / spec error-
    # isolation AC). Other detected skills' chains are still emitted.
    try:
        chain = self._registry.resolve_chain(name)
    except Exception as exc:
        _log.exception(
            "Failed to resolve skill dependency chain: skill={skill}, err={err}",
            skill=name,
            err=str(exc),
        )
        continue

    for skill in chain:
        if skill.name in seen:
            continue
        seen.add(skill.name)
        ordered_skills.append(skill)

# Existing dedup-against-session-loaded path, now applied to the expanded chain.
emitted_skills = [s for s in ordered_skills if s.name not in loaded_names]
```
