## Notes

- The `LastExchangeProcessor` is intentionally simpler than `SummaryProcessor` — direct field update with no SDK call. It runs in parallel with SummaryProcessor via the per-message pipeline's `asyncio.gather(return_exceptions=True)` pattern, ensuring independent error isolation.
- The `detect_boundary` signature change from `summary: str` to `session: Session` is a breaking change but only affects two call sites in coordinator.py.
- The cold start resume path creates a synthetic `Session(id="", ...)` since there's no active session. This keeps the boundary detector's interface clean.
- The project uses pragma-based migrations in `database.py`, not Alembic. The spec's mention of "Alembic migration" is generic.
