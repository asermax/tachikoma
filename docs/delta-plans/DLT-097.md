  - `_run_git(*args, cwd)` — run git, raise RuntimeError on failure

  - `_has_uncommitted_changes(cwd) → bool` — check `git status --porcelain`

#### Step 3: Create detect_divergence function

- Create: `src/tachikoma/git/sync.py` (append)
- What to do: Add `detect_divergence(cwd, remote, branch) → DivergenceStatus`:
  ```
  # Precondition: git fetch <remote> already called
  # Uses git merge-base --is-ancestor in both directions:
  # is remote/branch ancestor of HEAD? → at least AHEAD
  # is HEAD ancestor of remote/branch? → at least BEHIND
  # Both true → UP_TO_DATE (same commit)
  # Neither true → DIVERGED
  ```
- Test: `python -c "from tachikoma.git.sync import detect_divergence"`

#### Step 4: Create _try_naive_rebase function

- Create: `src/tachikoma/git/sync.py` (append)
- What to do: Add `_try_naive_rebase(cwd, remote_branch) → bool`:
  - Run `git rebase <remote_branch>` (e.g., `git rebase origin/main`)
  - Exit 0 → return True (clean rebase)
  - Exit non-zero → run `git rebase --abort` → return False
- Test: `python -c "from tachikoma.git.sync import _try_naive_rebase"`

#### Step 5: Create _agent_rebase function and prompt

- Create: `src/tachikoma/git/sync.py` (append)
- What to do: Add `CONFLICT_RESOLUTION_PROMPT` constant and `_agent_rebase(cwd, remote_branch, agent_defaults) → bool`:
  - CONFLICT_RESOLUTION_PROMPT: reference the exact prompt from design doc "Shared Logic" section — instructs agent to run `GIT_EDITOR=true git rebase {remote_branch}`, resolve conflicts, `git add`, `git rebase --continue`, loop until complete, or `git rebase --abort` on unresolvable
  - Construct ClaudeAgentOptions: `model="haiku"`, `permission_mode="bypassPermissions"`, `cwd=cwd`, `cli_path=agent_defaults.cli_path`, `env=agent_defaults.env`
  - Call `query(prompt=formatted_prompt, options=options)` and fully consume the generator per DES-005 (no break/return inside async for)
  - After agent completes, check if `.git/rebase-merge/` exists:
    - gone → return True
    - exists → `git rebase --abort` → return False
- Test: `python -c "from tachikoma.git.sync import _agent_rebase"`

#### Step 6: Create smart_push function

- Create: `src/tachikoma/git/sync.py` (append)
- What to do: Add `smart_push(cwd, remote, branch, agent_defaults) → PushResult`:
  ```
  1. _abort_stale_rebase(cwd)
  2. git fetch remote
  3. detect_divergence(cwd, remote, branch)
  4. UP_TO_DATE or BEHIND → NOTHING_TO_PUSH
  5. AHEAD → git push remote HEAD → PUSHED
  6. DIVERGED → _try_naive_rebase(cwd, f"{remote}/{branch}")
     → success: git push remote HEAD → REBASE_SUCCEEDED
     → failure: _agent_rebase(cwd, f"{remote}/{branch}", agent_defaults)
       → True: git push remote HEAD → AGENT_RESOLVED
       → False: REBASE_FAILED (local preserved)
  7. If push itself fails after successful rebase → PUSH_FAILED
  ```
  All exceptions caught internally → return enums. Log per DES-002.
  Branch note: workspace callers pass `branch="HEAD"`, submodule callers pass resolved branch name (e.g., `"main"`). Both are used to form `{remote}/{branch}` ref for divergence/rebase.
- Test: `python -c "from tachikoma.git.sync import smart_push"`

#### Step 7: Create smart_pull function

- Create: `src/tachikoma/git/sync.py` (append)
- What to do: Add `smart_pull(cwd, remote, branch, agent_defaults) → SyncResult`:
  ```
  1. _has_uncommitted_changes(cwd) → DIRTY_SKIPPED (early return)
  2. _abort_stale_rebase(cwd)
  3. git fetch remote
  4. detect_divergence(cwd, remote, branch)
  5. UP_TO_DATE → UP_TO_DATE
  6. BEHIND → git rebase {remote}/{branch} → FAST_FORWARDED
  7. DIVERGED → _try_naive_rebase(cwd, f"{remote}/{branch}")
     → success → REBASE_SUCCEEDED
     → failure → _agent_rebase(cwd, f"{remote}/{branch}", agent_defaults)
       → True → AGENT_RESOLVED
       → False → SYNC_FAILED
  ```
  All exceptions caught internally → return enums. Log per DES-002.
- Test: `python -c "from tachikoma.git.sync import smart_pull"`

#### Step 8: Update git package exports

- Modify: `src/tachikoma/git/__init__.py`
- What to do: Add re-exports: `smart_push`, `smart_pull`, `detect_divergence`, and result enums from `tachikoma.git.sync`
- Test: `python -c "from tachikoma.git import smart_push, smart_pull, PushResult, SyncResult, DivergenceStatus"`

#### Step 9: Restructure git_hook and add workspace sync

- Modify: `src/tachikoma/git/hooks.py`
- What to do: Restructure the hook's control flow. Current structure has an early return that blocks sync:

  **Before** (lines 32-52):
  ```python
  if git_dir.exists():
      _log.debug("Git repo already initialized...")
      return  # <-- Blocks sync!
  _log.info("Initializing git repo...")
  # ... init logic ...
  ```

  **After**:
  ```python
  # Init block: only runs if .git doesn't exist
  if not git_dir.exists():
      _log.info("Initializing git repo...")
      # ... init logic (unchanged) ...

  # Sync block: always runs after init check
  await _sync_workspace(workspace_path, ctx.settings_manager.settings)
  ```

  Add new `_sync_workspace(workspace_path, settings)` function:
  - Check if origin remote exists: `git remote get-url origin` (reuse `_run_git_command`)
  - No origin → debug log "No origin remote configured, skipping sync", return
  - Build AgentDefaults following __main__.py pattern:
    ```python
    merged_env = merge_env(settings.agent.env, auto_injected={"TZ": settings.tasks.timezone})
    agent_defaults = AgentDefaults(
        cwd=workspace_path,
        cli_path=settings.agent.cli_path,
        env=merged_env,
    )
    ```
  - Call `smart_pull(workspace_path, "origin", "HEAD", agent_defaults)`
  - Log result per DES-002:
    - DIRTY_SKIPPED → warning "Workspace has uncommitted changes, skipping sync"
    - UP_TO_DATE → debug "Workspace already up to date"
    - FAST_FORWARDED, REBASE_SUCCEEDED, AGENT_RESOLVED → info "Workspace synced: result=..."
    - SYNC_FAILED → warning "Workspace sync failed, continuing with local state"
  - All exceptions caught → warning log, continue (non-blocking)

  Add imports: `AgentDefaults`, `merge_env` from `agent_defaults`, `smart_pull` and `SyncResult` from `sync`.
- Test: `just test tests/git/test_hooks.py`
