## Batch 1: Envelope abstraction & coordinator refactor (no-behavior-change) — ✓ Done
Depends on: — (none)

This batch lands the envelope foundation. After completion the codebase has no `IncomingMessage`; every message-producing site constructs `TextMessage(...)` (semantic equivalent), and the coordinator's internal plumbing carries `MessageEnvelope` end-to-end. No behavioral change is visible to a typed-message user — `TextMessage.sdk_input == self.text` and `pinned_skills`/`force_new` are preserved.

> **Atomic landing**: Steps 1–5 form a single atomic refactor. Because Step 1 deletes `IncomingMessage` outright (per design KD-8: no alias), every file importing it stops compiling until Step 5 finishes the rename across the tree. Do **not** run `just typecheck`/`just test` between Steps 1–5; verification happens only at Step 6. If the implementation needs to pause mid-batch for any reason, the working tree should be left on Step 1 or after Step 5 — not in between.

#### Step 1: Define `MessageEnvelope` base and `TextMessage` subtype in `message.py`

- Modify: `src/tachikoma/message.py`
- What to do:
  - Replace the existing `IncomingMessage` dataclass entirely. Define `MessageEnvelope(ABC)` with the four property hooks. `sdk_input` is declared `@property @abstractmethod`; `pinned_skills`, `force_new`, and `runs_pre_processing` are non-abstract properties returning their defaults (`()`, `False`, `True`).
  - Define `TextMessage` as `@dataclass(frozen=True)` extending `MessageEnvelope`. Declare `text: str`, `pinned_skills: tuple[str, ...] = ()`, `force_new: bool = False` as dataclass fields. Override `sdk_input` with `@property def sdk_input(self) -> str: return self.text`. The `pinned_skills` and `force_new` dataclass fields shadow the base properties; this is intentional — the dataclass field set must match what producers construct today.
  - Refer to the design's "Implementation notes" under the Modeling section for the rationale on the `@property @abstractmethod` + frozen-dataclass coexistence.
- Snippet sketch:
  ```python
  # src/tachikoma/message.py
  from abc import ABC, abstractmethod
  from dataclasses import dataclass


  class MessageEnvelope(ABC):
      """Abstract base for the coordinator's message envelopes."""

      @property
      @abstractmethod
      def sdk_input(self) -> str: ...

      # Defaults on the base — subtypes override only what's actually different.
      @property
      def pinned_skills(self) -> tuple[str, ...]:
          return ()

      @property
      def force_new(self) -> bool:
          return False

      @property
      def runs_pre_processing(self) -> bool:
          return True


  @dataclass(frozen=True)
  class TextMessage(MessageEnvelope):
      """Envelope for typed user input (and any non-tap producer)."""

      text: str
      pinned_skills: tuple[str, ...] = ()
      force_new: bool = False

      @property
      def sdk_input(self) -> str:
          return self.text
  ```
