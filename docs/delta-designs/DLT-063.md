### Flagged Unknowns

#### S1 — MCP tool server structure
How should the MCP tool server be structured? The existing MCP servers (tasks, notifications, context, projects) are created at startup and passed to the coordinator. But this tool needs a channel-specific resource (the Telegram bot). Need to investigate whether the tool server can be conditionally created by the Telegram channel and injected into the coordinator's MCP server set.

#### S2 — Bot reference injection lifecycle
How to get the bot instance and chat ID into the tool server? The bot is created in `telegram.py`, but MCP servers are registered with the coordinator at construction time. Need to investigate the registration lifecycle — can the channel register additional MCP servers after coordinator creation, or does the tool server need to be initialized alongside the channel?
