| **S1** | Add `phase` class attribute to `PostProcessor` (default `MAIN_PHASE`), update `PostProcessingPipeline.register()` to read it | |
| **S2** | Refactor existing built-in processors to declare their phase as class attribute, remove explicit `phase=` at call sites | |
| **S3** | Add `post_processors` field to `TachikomaManifest` and `PluginManifest` | |

| **S5** | Add `post_processors: list[PostProcessor]` to `LoadedPlugin` dataclass | |
| **S6** | Extend `register_plugin_provider_listeners` to register/unregister plugin post-processors into `PostProcessingPipeline` on install/remove events | |
| **S7** | Add `unregister()` method to `PostProcessingPipeline` — safe no-op when processor not found, consistent with `PreProcessingPipeline.unregister()` pattern | |
