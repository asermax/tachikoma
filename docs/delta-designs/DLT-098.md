## Shape

| Part | Mechanism | Flag |
|------|-----------|:----:|
| **S1** | Stderr accumulator — callable that collects stderr lines into a buffer, provides retrieval with truncation support, silently swallows internal errors. Discarded after each SDK call. | |
| **S2** | Wrapped query() function — Tachikoma-level async generator that all standalone `query()` consumers switch to. Creates an S1 accumulator, installs it on `options.stderr`, delegates to the SDK's `query()`, and on `ProcessError` logs the accumulated stderr then re-raises. | |
| **S3** | ClaudeSDKClient options preparation — the coordinator and background task executor install an S1 accumulator on `ClaudeAgentOptions.stderr` before creating the client. Their existing error handlers (coordinator catches `CLIConnectionError`/`ProcessError`, executor catches `Exception`) extract and log accumulated stderr alongside their current error logging. | |
