## Shape

| Part | Mechanism | Flag |
|------|-----------|:----:|
| **S1** | Register aiogram message handlers for each media type (photo, voice, audio, document, sticker, video, video_note, animation) alongside the existing text handler | |
| **S2** | Media download service: download a Telegram media file to the temp folder using `bot.download()`, with file size pre-check and error handling; return the saved file path | |
| **S3** | Description builder: construct a type-specific text description from media metadata (dimensions, duration, title, etc.) plus the file path and optional caption | |
| **S4** | Bootstrap hook: create the dedicated temp folder on startup and delete files older than 30 days | |
| **S5** | Wire media handlers to enqueue the description text through the existing coordinator path (`enqueue()` + `_process_through_coordinator()`) | |
