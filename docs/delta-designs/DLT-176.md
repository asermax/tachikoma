### Flagged Unknowns

#### S7 — Maintenance schedule tiering mechanism
The current maintenance system runs on a single cron schedule. Tiering by day-of-week needs a mechanism to distinguish "today is Sunday" from "today is a weekday." This could be: (A) configure two separate cron schedules (weekday + Sunday), or (B) have the maintenance code check the day and decide which tier to run. The current scheduling infrastructure needs investigation to determine which approach fits.
