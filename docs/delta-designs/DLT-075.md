| **S1** | Per-message skills invocation — coordinator calls skills provider on every message, not just new sessions | |

| **S7** | Per-message error resilience — catch and log classification failures on subsequent messages without blocking | |

### Flagged Unknowns

#### S2 — Already-loaded skills tracking mechanism

The mechanism for determining which skills are already loaded in a session's context needs investigation. Options include:
- (a) Parse skill names from existing context entry XML content (fragile if format changes)
- (b) Maintain a separate structured tracking field/table per session
- (c) Add a `skill_names` or metadata field to context entries for reliable extraction

The chosen approach must be robust against format changes and performant (called on every message).
