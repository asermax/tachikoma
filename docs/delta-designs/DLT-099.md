### Flagged Unknowns

#### S4 — Crash recovery archival
Crash-recovered sessions get their `ended_at` set by the recovery hook but don't go through the post-processing pipeline. How should transcript archival be triggered for these sessions? Options include: extending the existing recovery hook to also copy transcripts, adding a separate bootstrap hook that scans for un-archived transcripts, or deferring to DLT-066 (post-processing recovery on restart) which would eventually re-run all processors for interrupted sessions.
