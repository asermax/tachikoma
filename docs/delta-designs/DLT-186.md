### Flagged Unknowns

#### S6 — Markdown and YAML formatting under biome 2.6

biome 2.5.8 does not process Markdown or YAML; 2.6.8 formats both. Run read-only over the whole repo, it flags 81 files: 67 under `docs/`, the 12 agent-facing Markdown files under `src/` (references and `SKILL.md`), `CHANGELOG.md` and `pnpm-workspace.yaml`. Its changes are table padding, `*emphasis*` to `_emphasis_`, `*` list bullets to `-`, and single to double quotes in YAML.

`CHANGELOG.md` is written by semantic-release on every release with `*` bullets, so with Markdown formatting on it has to be excluded from biome or each release commit leaves lint failing.

The policy — adopt the new formatting, keep it off, or adopt it for `src/` only — is being decided with the user. Until then the spec's R9 criterion is worded conditionally.

## Notes

Decisions taken during speccing, recorded in the spec and not to be re-litigated in design:

- `typebox` stays in lockstep with pi (1.3.27); 1.4.7 is held back.
- pi 1.6's default behavior is adopted as-is, including prompt-cache warming between runs (`cacheWarming: "idle"`); Tachikoma sets no override.
- The Telegram acceptance check is manual, performed by the maintainer after implementation; there is no automated boot smoke.
- Moving `SideRunner` off pi-ai's temporary `/compat` entry is a follow-up delta.
- `semantic-release` stays on 25.x because 26 needs Node ≥ 26.13 and the release workflow runs Node 24.

Trial run against the target versions (2026-11-24, scratch copy, nothing committed):

- With only the pi packages at 1.6.0, `tsc --noEmit` reports 21 errors, all from the two root causes in the spec (`StringEnum`, the `before_agent_start` union), and all 2184 tests pass with the source untouched.
- With every dependency at latest plus those two fixes, typecheck and `pnpm run build` are clean and the suite is green except `tests/skills/suggest.test.ts`, whose hand-built `before_agent_start` event lacks `messageType`.
- Tests are not typechecked by the gate (`tsconfig.json` includes only `src`), so hand-built pi event fixtures must be updated by hand.
- biome 2.6.8 starts formatting Markdown and YAML and flags 81 files repo-wide (see S6); it also reports `lint/complexity/useMathMinMax` at `src/extensions/workflows/repository.ts:148`. A first count of 12 came from a trial that copied only `src/`, `tests/` and `scripts/`.
- drizzle-kit 0.31.11 reports no schema changes; the lockfile shrinks slightly.
