### Flagged Unknowns

None. Every part's mechanism is understood: trial runs against the target versions during speccing resolved the open questions (see Notes).

One hazard is settled by exclusion rather than investigation, and the design should keep it visible: biome 2.6's Markdown formatter is not frontmatter-aware. On a `SKILL.md` it inserts a blank line after the opening `---` and strips the indentation of the YAML frontmatter description, which leaves the skill unloadable. On `DELTAS.md` it puts a blank line between each delta heading and its status line, which the planning script cannot read. Both are excluded from biome for that reason. A future Markdown file with YAML frontmatter or a tool-parsed layout needs the same exclusion; ADR-010 records the rule.

## Notes

Decisions taken during speccing, recorded in the spec and not to be re-litigated in design:

- `typebox` stays in lockstep with pi (1.3.27); 1.4.7 is held back.
- pi 1.6's default behavior is adopted as-is, including prompt-cache warming between runs (`cacheWarming: "idle"`); Tachikoma sets no override.
- The Telegram acceptance check is manual, performed by the maintainer after implementation; there is no automated boot smoke.
- Moving `SideRunner` off pi-ai's temporary `/compat` entry is a follow-up delta.
- biome 2.6's Markdown and YAML formatting is adopted, with `CHANGELOG.md`, `docs/planning/DELTAS.md` and `SKILL.md` files excluded from biome; the user's condition was that it must not break anything.
- `semantic-release` stays on 25.x because 26 needs Node ≥ 26.13 and the release workflow runs Node 24.

Trial run against the target versions (2026-11-24, scratch copy, nothing committed):

- With only the pi packages at 1.6.0, `tsc --noEmit` reports 21 errors, all from the two root causes in the spec (`StringEnum`, the `before_agent_start` union), and all 2184 tests pass with the source untouched.
- With every dependency at latest plus those two fixes, typecheck and `pnpm run build` are clean and the suite is green except `tests/skills/suggest.test.ts`, whose hand-built `before_agent_start` event lacks `messageType`; giving that fixture `messageType: "user"` makes it green.
- Tests are not typechecked by the gate (`tsconfig.json` includes only `src`), so hand-built pi event fixtures must be updated by hand.
- biome 2.5.8 does not process Markdown or YAML; 2.6.8 formats both (table padding, `*emphasis*` to `_emphasis_`, `*` bullets to `-`, quote style in YAML) and reports `lint/complexity/useMathMinMax` at `src/extensions/workflows/repository.ts:148`. `biome migrate` only updates the schema URL and turns `rules.recommended` into `rules.preset`.
- Formatting everything breaks two things: `tests/agent/force-load-skills.test.ts` loses two tests because the two built-in `SKILL.md` files stop loading, and `deltas.py` reads every delta as not started. `CHANGELOG.md` is rewritten by semantic-release with `*` bullets on every release, so it would leave lint failing after each release.
- With those three excluded, 77 files are reformatted (66 under `docs/`, 10 reference files under `src/`, `pnpm-workspace.yaml`). A combined trial — every dependency at its target version, the two source fixes, the fixture, and that formatting — passes `biome check`, `tsc --noEmit`, `vitest run` (157 files, 2184 tests) and `pnpm run build`.
- drizzle-kit 0.31.11 reports no schema changes; the lockfile shrinks slightly.
